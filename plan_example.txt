ПРИМЕР plan.json С ПОЯСНЕНИЯМИ (AutoEdit)
==========================================

Это НЕ настоящий JSON-файл — это plan.json с комментариями на русском,
чтобы было понятно, что означает каждое поле. Комментарии начинаются
с "//". В настоящем plan.json комментариев быть не должно (JSON их не
поддерживает) — просто уберите строки с "//" и получится рабочий файл.

Демо-проект с уже рабочим примером можно создать командой:
    autoedit demo ./my_demo
и посмотреть получившийся plan.json там — это тот же пример, но без
комментариев и с фальшивыми (сгенерированными) файлами вместо настоящих.

Ниже — план для примера "документалка про 438 дней в океане" (как
проект пользователя).


{
  // Название ролика. Просто для отчёта, на сам монтаж не влияет.
  "title": "438 дней",

  // Список файлов озвучки, по порядку. Если несколько файлов — они
  // склеиваются один за другим (как будто это один длинный файл).
  // Пути — относительно папки проекта (там же, где лежит plan.json).
  "voice": ["voice/full.mp3"],

  // Общий "вид" картинки для всего ролика — необязательное поле.
  // grain — зернистость плёнки (0 = нет, 0.3 = заметная, больше 0.5 — много).
  // vignette — затемнение по краям кадра (0 = нет, 0.3 = заметное).
  // lut — путь к LUT-файлу (.cube) для цветокоррекции, необязательно.
  "look": {
    "grain": 0.15,
    "vignette": 0.2
  },

  // Список кадров ролика, ПО ПОРЯДКУ. Именно в этом порядке они попадут
  // в финальный ролик (кроме случая с "anchor" — см. ниже).
  "shots": [
    {
      // Уникальный идентификатор кадра. Просто для вас и для отчётов/
      // предупреждений ("кадр D01: ...") — придумайте любой, лишь бы
      // не повторялся.
      "id": "D01",

      // СПОСОБ 1 РАСПОЛОЖЕНИЯ КАДРА ВО ВРЕМЕНИ — "anchor":
      // это фраза (или кусок фразы) из озвучки, дословно как она
      // произносится. Программа находит эту фразу в распознанной
      // озвучке (через faster-whisper) и кадр начинается ровно там,
      // где эта фраза начинает звучать. Длительность кадра тогда — до
      // начала СЛЕДУЮЩЕГО кадра (если только явно не задано "duration").
      //
      // ВАЖНО: кадры с "anchor" должны идти в plan.json В ТОМ ЖЕ
      // ПОРЯДКЕ, в котором фразы реально звучат в озвучке. Если
      // порядок не совпадёт — рендер остановится с ошибкой (это
      // защита от того, чтобы случайно не перепутать кадры местами).
      // Если вы точно знаете, что делаете (например, специально
      // показываете кадр забегая вперёд по смыслу) — есть флаг
      // --allow-reorder, который превращает эту ошибку в предупреждение.
      "anchor": "он провёл 438 дней в открытом океане",

      // СПОСОБ 2 РАСПОЛОЖЕНИЯ КАДРА — явные "start" и "duration" (в
      // секундах от начала озвучки). Используйте это вместо anchor,
      // если озвучки ещё нет или для этого кадра точная привязка к
      // словам не важна (например, заставка, которая должна начаться
      // строго на 0-й секунде). Нельзя одновременно указывать и
      // "anchor", и "start" — нужно выбрать один способ.
      // "start": 0.0,
      // "duration": 4.0,

      // Путь к видео- или фото-файлу для этого кадра, относительно
      // папки проекта.
      "asset": "assets/ai/438days_survivor_portrait.mp4",

      // С какой секунды ИСХОДНОГО файла начинать (если не с начала).
      // Необязательно, по умолчанию 0.
      "source_start": 2.0,

      // Как "оживить" статичную картинку/видео: zoom_in, zoom_out,
      // pan_left, pan_right, rise (медленное движение вверх), static
      // (без движения). Необязательно, по умолчанию static.
      "motion": "zoom_in",

      // Насколько сильно движение, от 0 до 1 (0.05-0.1 — еле заметно,
      // 0.3+ — сильно). Необязательно, есть значение по умолчанию.
      "motion_amount": 0.08,

      // Как кадр появляется: cut (обычная склейка), crossfade (плавное
      // перетекание из предыдущего кадра), fade_from_black (из чёрного).
      // Необязательно, по умолчанию cut.
      "transition_in": "fade_from_black",

      // Длительность перехода в секундах, если transition_in не cut.
      // Необязательно, по умолчанию 0.5.
      "transition_duration": 0.6,

      // Обрезка кадра ДО того, как применяется motion: [x, y, w, h],
      // все числа — доли от 0 до 1 (например [0.1, 0.1, 0.6, 0.6] —
      // взять кусок начиная с 10% от левого края и 10% сверху, шириной
      // и высотой 60% от исходного кадра). Необязательно.
      // "crop": [0.1, 0.1, 0.6, 0.6],

      // Как источник вписывается в кадр ролика, если пропорции не
      // совпадают (например, вертикальное видео в горизонтальном
      // ролике): "cover" (обрезать, заполнить весь кадр — по
      // умолчанию, если ориентация совпадает), "contain" (вписать
      // целиком, с чёрными полосами), "blur_fill" (вписать целиком, а
      // пустые места по бокам/сверху-снизу — размытая растянутая копия
      // того же кадра, а не чёрные полосы). Если не указано и
      // ориентация источника не совпадает с ориентацией ролика —
      // автоматически выбирается blur_fill.
      // "fit": "blur_fill",

      // Текст, который появится на кадре (субтитр-плашка, не путать с
      // subtitles.srt — это отдельная надпись поверх картинки).
      "text": "438 ДНЕЙ В ОКЕАНЕ БЕЗ ЕДЫ И ВОДЫ",

      // Оформление текста — необязательно, если не указано, берутся
      // значения по умолчанию.
      "text_style": {
        "size": 48,               // размер шрифта (при ширине ролика 1920px)
        "position": "bottom",     // top / center / bottom
        "color": "white",         // цвет текста
        "stroke": true,           // чёрная обводка вокруг букв (для читаемости)
        "shadow": true,           // тень под текстом
        "highlight": "438 ДНЕЙ",  // часть текста, которую выделить цветом
        "highlight_color": "yellow"
      },

      // Дополнительные видео поверх основного кадра (например, карта,
      // архивная вставка на хромакее). Необязательно.
      "overlays": [
        {
          "asset": "assets/graphics/map_pacific.mp4",
          "chroma_key": "#00FF00",  // если у оверлея зелёный/синий фон — вырезать его
          "offset": 0.3             // на какой секунде кадра появится оверлей
        }
      ],

      // Звуковые эффекты, привязанные к этому кадру (например, свист
      // ветра, щелчок). Необязательно.
      "sfx": [
        {"asset": "assets/sfx/wind_gust.wav", "offset": 0.0, "volume": 0.7}
      ],

      // Пауза (тишина в музыке) перед этим кадром, в секундах — чтобы
      // усилить драматический момент. Необязательно.
      "silence_before": 0.5,

      // ЗАЧЕМ этот кадр — для вас и для отчёта report.txt. Настоятельно
      // рекомендуется заполнять: если пропустить, программа выдаст
      // предупреждение (не ошибку, но отчёт станет менее полезным).
      "why": "Открытие: главный герой, драматичная цифра 438 дней",

      // "Драматургический такт" — на каком этапе истории кадр
      // (preparation / focus / pause / reveal / consequence).
      // Необязательно, только для отчёта/статистики.
      "beat": "preparation",

      // Название главы — кадры с одинаковым chapter группируются в
      // одну главу. Используется, например, в режиме --check-audio-only
      // (чёрный экран с подписями глав вместо видео). Необязательно.
      "chapter": "Пролог",

      // Кадр сгенерирован ИИ (true) или это реальные съёмки/архив
      // (false)? Только для статистики в отчёте (сколько ИИ-контента
      // в ролике) — на сам рендер не влияет. Необязательно.
      "is_ai": true
    },

    {
      "id": "D02",
      "anchor": "рыболовецкое судно вышло из порта",
      "asset": "assets/stock/boat_harbor.mp4",
      "motion": "pan_right",
      "why": "Контекст: с чего началась история",
      "beat": "focus",
      "chapter": "Пролог",
      "is_ai": false
    }
  ],

  // Фоновая музыка. Можно несколько треков (например, разная музыка
  // для разных глав) — они не обязаны покрывать весь ролик целиком.
  "music": [
    {
      "asset": "assets/music/tension_theme.mp3",

      // СПОСОБ 1: привязка к озвучке через anchor-фразы — музыка
      // играет от начала фразы from_anchor до начала фразы to_anchor.
      "from_anchor": "он провёл 438 дней",
      "to_anchor": "спасатели заметили лодку",

      // СПОСОБ 2: явные секунды вместо anchor (нельзя смешивать оба
      // способа в одном треке — либо anchor, либо start/end).
      // "start": 0.0,
      // "end": 45.0,

      "volume": 0.18,     // громкость музыки (0-1), при голосе музыку приглушает автоматически
      "fade_in": 1.0,     // плавное появление, сек
      "fade_out": 2.0     // плавное затухание, сек
    }
  ],

  // Финальная заставка/титры в конце ролика. Необязательно.
  "end_screen": {
    "asset": "assets/graphics/subscribe_screen.mp4",
    "duration": 5
  }
}


ЧТО ДЕЛАТЬ ДАЛЬШЕ
==================
1. autoedit check <папка_проекта>        — проверить план на ошибки
2. autoedit render <папка_проекта>       — собрать черновик (preview.mp4)
3. autoedit render <папка_проекта> --final   — собрать финал в хорошем качестве
   (или одной командой: autoedit build <папка_проекта> — check + preview + final)

Подробное описание всех команд — в файле ИНСТРУКЦИЯ.txt.
