# AutoEdit

Программа для чернового автомонтажа документальных YouTube-роликов по
готовому монтажному плану (`plan.json`). Программа не принимает
творческих решений — она точно исполняет план и сообщает о проблемах.

Общий план проекта и рассуждения монтажёра — в файле
[`../AUTOEDIT_PLAN.md`](../AUTOEDIT_PLAN.md). Здесь описано только то,
что уже реализовано (этап 1).

## Что уже умеет программа (этап 1)

- `autoedit check <папка_проекта>` — проверяет `plan.json` и все файлы,
  на которые он ссылается, печатает найденные ошибки/предупреждения и
  сохраняет отчёт в `<папка_проекта>/output/report.txt`.
- `autoedit demo [папка]` — создаёt тестовый проект с фальшивыми
  ассетами (цветные заглушки вместо видео, тон вместо голоса) и
  небольшим `plan.json`, чтобы проверить программу без ваших реальных
  файлов.

Распознавание речи, реальный видео/аудио-рендер, отчёт по всем
правилам монтажёра и экспорт таймлайна появятся на следующих этапах —
подробности в `AUTOEDIT_PLAN.md`.

## Установка

1. Нужен **Python 3.11 или новее**. Проверить версию:
   ```
   python3 --version
   ```
2. Нужен **FFmpeg** — программа для работы с видео (используется
   рендером и генератором демо-проекта). Команда `autoedit check`
   сама проверяет, установлен ли он, и подсказывает команду для вашей
   операционной системы (macOS — Homebrew, Windows — winget, Linux —
   apt или аналог вашего дистрибутива).
3. Установите саму программу (из корня репозитория):
   ```
   pip install -e .
   ```
   Это делает команду `autoedit` доступной в терминале. Флаг `-e`
   означает, что изменения в коде сразу подхватываются без переустановки.

## Быстрая проверка на демо-проекте

```
autoedit demo
autoedit check ./autoedit_demo_project
```

Первая команда создаст папку `autoedit_demo_project` с фальшивыми
файлами и планом. Вторая — проверит план и покажет отчёт. Так можно
убедиться, что всё работает, не трогая ваши реальные ролики.

## Проверка своего проекта

Разложите проект в такую структуру:

```
project/
  plan.json
  voice/               озвучка (mp3/wav)
  assets/ai/           ИИ-клипы и картинки
  assets/stock/        стоковые видео
  assets/graphics/     графика (mp4, png), в т.ч. *_greenscreen.mp4
  assets/maps/         пролёты Google Earth
  assets/sfx/          звуковые эффекты
  assets/music/        музыка
  lut/                 необязательно: цветовой LUT (.cube)
```

И запустите:

```
autoedit check project/
```

## Формат plan.json (кратко)

```json
{
  "title": "438 Days",
  "voice": ["voice/full.mp3"],
  "shots": [
    {
      "id": "H01",
      "anchor": "Imagine leaving home",
      "asset": "assets/ai/I1_boat_leaving.mp4",
      "motion": "zoom_in",
      "transition_in": "cut",
      "why": "открываем с обложки: зритель видит, что попал куда нужно",
      "beat": "preparation",
      "chapter": "Intro"
    }
  ]
}
```

- Время кадра задаётся либо через `"anchor"` (привязка к словам
  диктора — заработает на этапе 2), либо явно через `"start"` и
  `"duration"` (в секундах).
- Допустимые значения `motion`: `zoom_in`, `zoom_out`, `pan_left`,
  `pan_right`, `rise`, `static`.
- Допустимые значения `transition_in`: `cut`, `crossfade`,
  `fade_from_black`.
- Допустимые значения `beat`: `preparation`, `focus`, `pause`,
  `reveal`, `consequence`.
- Полное описание всех полей — в `AUTOEDIT_PLAN.md`.

## Частые ошибки

- **«Файл плана не найден»** — в указанной папке нет `plan.json`.
  Проверьте путь, который вы передали команде `autoedit check`.
- **«план... повреждён (невалидный JSON)»** — в файле опечатка
  (например, лишняя или пропущенная запятая/кавычка). В сообщении
  указана строка и столбец — откройте файл в редакторе с подсветкой
  JSON и найдите это место.
- **«Кадр X: файл не найден»** — путь к ассету в плане не совпадает с
  реальным расположением файла. Пути в плане пишутся относительно
  папки проекта (например `assets/ai/clip.mp4`).
- **«FFmpeg: НЕ найден»** — установите FFmpeg по подсказке, которую
  печатает программа для вашей операционной системы.

## Тесты

```
python -m unittest discover -s tests
```

Тест демо-проекта автоматически пропускается, если в системе не
установлен FFmpeg.
