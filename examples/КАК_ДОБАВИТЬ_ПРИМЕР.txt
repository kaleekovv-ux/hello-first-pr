ПАПКА ПРИМЕРОВ
==============

Сюда кладите свои удачные монтажные планы — Claude смотрит на них,
когда составляет новый план, и делает в вашем стиле.

Что положить:
1. plan.json ролика, который вам понравился, — переименуйте понятно,
   например 438_days_plan.json.
2. По желанию — сценарий этого ролика рядом: 438_days_script.txt.
3. По желанию — расшифровку чужого документального ролика, структура
   которого нравится (можно попросить Claude взять её через vidIQ):
   любимый_ролик_transcript.txt.

Как отправить на GitHub (в PowerShell, из папки hello-first-pr):
    git add examples
    git commit -m "Пример монтажа"
    git push

Или просто пришлите файл Claude в чате и попросите положить его сюда.
